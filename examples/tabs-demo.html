Tabs

Click a tab, or focus one and use the arrow keys. Home and End jump to the ends. Selected panel is the only one not hidden.

Panels are plain divs. The component only toggles the hidden attribute and the aria-selected / tabindex on the tabs. Style them however you like.

Drop the script in and construct it with a selector:

new DemoTabs('#demo-tabs', { activate: 0 });
  • select(index) — 0-based
  • selectById(tabElementId) — handy for deep links
  • event tabs:change with detail.index, .panel, .previous
  • option orientation: 'vertical' switches the arrow keys to Up/Down

Every tab needs a matching panel via aria-controls. If one is missing the constructor throws instead of failing silently. I'd rather find out immediately.
